# 全字庫正楷體（TW-Kai）

本目錄的 `*.woff2` 是全字庫正楷體的 subset（改作），由 `apps/web/scripts/fonts/build-twkai-subset.py` 產生，
只用在 PDF 匯出（票券 18）。

來源出處：數位發展部，CNS11643中文標準交換碼全字庫網站，https://www.cns11643.gov.tw。

授權：政府資料開放授權條款－第 1 版（https://data.gov.tw/license）。全字庫網站同時以
開放字型授權條款 OFL-1.1（https://opensource.org/licenses/OFL-1.1）授權；本專案依前者使用。
