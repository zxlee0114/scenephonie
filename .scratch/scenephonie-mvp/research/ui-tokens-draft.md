# 暫定的 Typography 與色彩系統

For: [票券 26](../issues/26-ui-visual-direction.md)。討論在 [`./ui-visual-direction.md`](./ui-visual-direction.md)，圖片素材在 [`./assets/ui/`](./assets/ui/README.md)。

> **⚠️ 這份檔案是暫定值，不是規範。** 票券 26 未 resolve 之前，這裡的任何一個數字都不得被實作引用。
>
> **為什麼是 markdown 而不是 CSS／JSON**：(1) 現在還沒有 app，CSS 沒有家可以放；(2) 暫定值需要一欄「**為什麼是這個值**」，那是 CSS 與 JSON 裝不下的，而在票券 26 定案前，理由比值本身重要；(3) 它是本效力這批 UI 素材裡**唯一會直接畢業成程式碼**的東西，獨立成檔，畢業時不必從長文件裡挖。

## 2. 色彩

> **暫定期用色階名（`--gray-500`），不用語意名（`--color-scene-number`）。**
> 語意要等票券 26 的畫面清單定了才知道有哪些角色，太早命名會綁死。
> 定案時再加一層語意別名指向色階。

從規格書掉出來、遲早需要一個顏色的角色。**先列出來，不急著配值** —— 這張表的長度本身就是「色彩系統要多大」的答案。

| 角色 | 出處 | 備註 |
|---|---|---|
| 場次號、子場次號 | [規格書 §5.4](../spec.md) | decoration，⚠️ 必須看得出「這不是我打的字」 |
| 草稿場次標籤 | [規格書 §11](../spec.md)、F6 | 推導狀態，且**擋匯出** —— 需要一個帶警示意味的顏色 |
