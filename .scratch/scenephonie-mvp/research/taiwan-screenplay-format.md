## 逐項回答

### 1. 頁面設定（紙張尺寸、邊界、字型、字級、行距）

| 項目 | MOC | GHSA | TNUA |
|---|---|---|---|
| 紙張方向/排版 | 未在本 PDF 中說明 | 「直式橫書正體（繁體）中文」 | 「直式橫書排版（橫向書寫）」 |
| 字級 | 未說明 | 「12 級字」 | 「12pt」 |
| 中文字型 | 未說明 | 未說明 | 標楷體 |
| 英文字型 | 未說明 | 未說明 | Calibri |
| 行距 | 未說明 | 未說明 | 16pt |
| 邊界 | 未說明 | 未說明 | 上下 2.54cm，左右 3.17cm |
| 頁碼 | 未說明 | 未說明（但要求全篇壓浮水印字樣） | 頁尾置中，可加浮水印 |
| 紙張尺寸（A4 等） | 三份範本皆未明說 | | |

**觀察**：GHSA 的「12 級字」與 TNUA 的「12pt」數值上一致，但這是巧合還是業界公約，範本無法確認。邊界、字型、行距、紙張尺寸這幾項，**只有 TNUA 一份範本提供具體數字**，MOC／GHSA 完全沒有規定頁面設定，只規定內文的「寫作格式」（場次標題、動作、對白的排列規則）。

### 2. 場次標題結構

三份範本的場次標題欄位與順序都是：

```
[場次號]. [內/外景] [地點] [時間（日/夜/晨/昏）] [人物列表，僅 TNUA 要求]
```

- **MOC／GHSA**：`1. 內景/外景 地點 日/夜/晨/昏`　— **不含人物欄位**。範例：`1. 內景 阿強家客廳 夜`
- **TNUA**：`內景/外景 地點 日/夜/晨/昏 人物` — **明確要求列出該場所有登場人物**，範例：`1.內景 教室 白天 小芸、阿良`；並註明「若該場同時跨內與外，可以『內/外景』標註」

三者皆未以簡表（表格）呈現場次標題，全部是行內文字（一行純文字）。**三份範本都沒有觀察到簡表用法**——這與票券背景描述的「簡表已被簡化掉」一致，但因為找不到任何仍在使用簡表的官方範本，這點只能算間接印證，不是直接證據。

TNUA 額外規定場次標題「以粗體標示」；MOC／GHSA 範例中場次標題視覺上未見加粗（但這是從 PDF 圖像判讀，非文字屬性確認，信心中等）。

### 3. 動作與對白的排版規則

**動作**：
- MOC／GHSA：動作文字左靠、不縮排、無任何符號前綴。段落間以空行分隔（觀察自範例排版，非文字明訂規則）。
- TNUA：明訂「在敘述句前加『△』表示動作或場景敘述」，範例逐行都加了 △。

**對白**：三份範本都各自展示（或規定）了兩種對白呈現法：

- **MOC／GHSA 範例一（行內式）**：`人物名：對白內容` 同一行，人物名後接全形冒號，不換行、不置中、不縮排，多句對白連續時中間不特別空行；此整段對白與前後動作之間各空一行。
- **MOC／GHSA 範例二（分行置中式）**：人物名獨占一行、置中，其後（不接冒號）換行寫對白，對白置中並整段縮排（比動作文字更靠內側）；每個「人物名+對白」區塊前有空行。
- **TNUA（規定，非範例變體）**：人物名置中、名字後加冒號，對白寫在下一行並置中；「對白前後須空一行」是明文規定。這接近 MOC/GHSA 的範例二，但 TNUA 的人物名後方「有加冒號」，而 MOC/GHSA 範例二的人物名後方**不加冒號**（冒號只出現在範例一的行內式）。

**小結**：MOC／GHSA 把「行內式」與「置中分行式」都列為可接受的參考範例，沒有強制單一寫法；TNUA 則只規定一種（置中分行＋人物名後加冒號）。

### 4. metadata 呈現方式的差異；△ 等符號的使用時機

- 三份範本中，**只有 TNUA 使用 △ 符號**，且是明文規定「在敘述句前加△表示動作或場景敘述」，逐行動作都加。
- **MOC 與 GHSA 的範例完全沒有使用 △ 或任何符號標記動作**，動作文字就是純段落文字，靠空行與對白區隔。
- 三份範本都**沒有出現簡表**（表格化的場次 metadata），場次 metadata 一律以行內文字呈現在場次標題那一行。
- GHSA 徵件規定要求劇本正文之外另外提供「人物介紹」（角色小傳，非場次內的 metadata）與「長版劇情大綱」（800–1200 字），這兩者是**投稿包裝要求**，不是場次本身的排版規則，也不屬於本專案「投影」概念下的分場大綱（後者只顯示摘要，前者要求完整介紹文字）。

### 5. 三份範本之間的具體差異點（逐項比對，標明硬性/習慣）

| 項目 | MOC/GHSA | TNUA | 判斷 |
|---|---|---|---|
| 場次標題含人物 | 不含 | 含，且「該場出現人物皆須列出」 | TNUA 明文「須」= 硬性；MOC/GHSA 未提及，無法判斷是否禁止 |
| △ 符號標記動作 | 未使用 | 明文規定使用 | TNUA 硬性；MOC/GHSA 的「無符號」是否為硬性規則亦不明，只能說範例中未使用 |
| 場次標題加粗 | 未觀察到明顯加粗 | 明文規定「以粗體標示」 | TNUA 硬性；MOC/GHSA 未規定 |
| 對白人物名後加冒號 | 範例一：加；範例二：不加 | 明文規定「加冒號」 | 不算硬性差異，MOC/GHSA 本身兩種範例就不一致，屬於「習慣／可選」 |
| 對白前後空行 | 範例中觀察到有空行，但未見文字明訂 | 明文規定「對白前後須空一行」 | TNUA 明文＝硬性；MOC/GHSA 只是範例呈現的習慣 |
| 新場次前空行 | 範例中場次間有空行，未見文字明訂具體行數 | 明文規定「每個新場次前須空兩行」 | TNUA 硬性且具體（兩行）；MOC/GHSA 無法確認具體行數 |
| 頁面設定（字型/邊界/行距） | GHSA 只規定字級 12 級字＋直式橫書；MOC 未提及 | 完整規定（字型、邊界、行距、頁碼） | 差異最大的一塊；GHSA 屬官方硬性徵件規定，TNUA 屬校內教學規定 |
| 投稿包裝（封面、大綱、人物介紹、浮水印、不得署名） | GHSA 明文規定；MOC 範本未含此段落（只有內文格式參考） | 未提及（TNUA 是單一劇本作業格式，非徵件） | GHSA 硬性（徵件須知第四點第十款）；不適用於 TNUA 情境，也未必適用本專案 v1 |
| 簡表 | 未出現 | 未出現 | 三者一致：均未使用；無法判斷是否曾為硬性規定後被廢除，範本本身無法佐證 |

### 6. 場次編號慣例（是否有插入場次如 12A 的處理方式）

**三份範本都沒有觀察到，也沒有任何文字提及插入場次（如 12A、12a、12之1）的編號慣例。** 三份範本中的場次編號都只是簡單的連續阿拉伯數字（1、2、3、4…），因為範例劇本本身很短（4 場），完全沒有測試過插入或刪除場次後如何重新編號或用什麼記號標示插入場次的情境。

**明確結論：範本未規範。** 這不是「找不到所以推測沒有」，而是三份一手範本的示範內容與說明文字中，完全沒有出現任何與插入場次編號相關的字樣、符號或規則描述。若本專案要支援插入場次的編號慣例（例如 12A），需要另外查證業界實務（可能來源：好萊塢式劇本軟體如 Final Draft 的慣例、台灣製片統籌／場記的實務訪談、或直接自訂一套規則），這三份範本無法作為依據。

## v1 要實作的格式（文化部劇本獎格式）

以下規則綜合 MOC 範本本身內容 + 其明確聲明沿用的 GHSA 徵件須知規定。**標示「MOC/GHSA 明文」的是可直接依據的硬性規則；標示「觀察自範例、非明文」的是從排版範例反推、信心較低，實作時建議先徵詢確認。**

**場次標題**：
- 格式：`[場次號]. [內景/外景] [地點] [日/夜/晨/昏]`（MOC/GHSA 範例一致）
- **不含人物欄位**（觀察自範例——兩份範例的場次標題都沒有列人物；但沒有文字明訂「不可列」，只是範例中沒有這麼做）
- 場次號為連續阿拉伯數字，後接半形句點（`1.` `2.` `3.`）（觀察自範例）
- 未觀察到粗體或其他強調樣式（觀察自範例，信心中等，PDF 圖像判讀）

**動作**：
- 純文字段落，靠左對齊，不縮排，**不加任何符號前綴**（不用 △）（觀察自範例，MOC/GHSA 兩份範例皆未使用符號）
- 段落之間以空行分隔（觀察自範例）

**對白**：
v1 應選定一種呈現方式並保持一致（MOC/GHSA 範例本身展示了兩種變體，未強制擇一）：
- **建議採用「行內式」**（範例一）：`人物名：對白內容`，人物名後接全形冒號，同一行接續寫對白，不置中、不額外縮排。理由：這種格式資訊密度較高、對「格式與內容脫鉤」的結構化資料模型（人物名與對白分離存成欄位，渲染時才組成該行）較友善，且與本專案「動作」「對白」分離儲存的資料模型自然對應。
- 若要支援「置中分行式」（範例二）作為輸出格式選項，需額外實作置中對齊與整段縮排，人物名獨占一行且不加冒號。
- 對白與前後動作之間以空行分隔（觀察自範例；GHSA 沒有像 TNUA 那樣明文規定「須空一行」，但兩份範例都一致有空行）

**頁面設定**：
- **無法從 MOC/GHSA 兩份 PDF 中確認**紙張尺寸、邊界公分數、字型名稱、行距數值。GHSA 徵件須知只明文規定「直式橫書正體（繁體）中文 12 級字」，其餘（邊界、字型、行距、紙張尺寸）**未規定或本次取得的範本文件中沒有涵蓋**。
- 若 v1 要有具體頁面設定數字，**不能沿用 TNUA 的數字冒充 MOC/GHSA 規範**（那是另一套獨立規範），需要另外找 MOC/GHSA 的完整徵件須知全文（本次只取得 4 頁的「內文寫作格式參考」節錄，未必是全份須知）或直接詢問主辦單位。

**簡表**：v1 不需要實作簡表呈現——三份範本均未使用，MOC/GHSA 場次 metadata 一律行內呈現。

**投稿包裝規則（是否適用 v1 待確認）**：GHSA 徵件須知規定 PDF 需附長版劇情大綱（800–1200 字）、人物介紹、不得署名、需壓浮水印。這些是「徵件」情境的規定，**MOC 範本文件本身沒有重複這些規定**，不確定是否也適用於文化部劇本獎的實際投稿情境，也不確定是否該套用到本專案的一般匯出情境（v1 匯出的 PDF 未必是要拿去投稿比賽）。建議視為 v1 的「不確定與缺口」，先不強制實作。

## 未來多格式輸出需要參數化的維度

基於三份範本的差異，以下維度應該做成「輸出格式」設定，讓劇本內容與呈現規則脫鉤：

1. **頁面設定**：紙張尺寸、邊界、字型（中/英文分開設定）、字級、行距、頁碼位置、是否加浮水印
2. **場次標題是否含人物欄位**（MOC/GHSA 不含，TNUA 含）
3. **場次標題是否加粗**
4. **動作是否加符號前綴**（△ 有/無），以及符號本身（△ 是 TNUA 用的，未必是唯一符號）
5. **對白呈現方式**：行內式 vs 置中分行式；人物名後是否加冒號；對白是否置中/縮排
6. **對白前後空行規則**（是否強制、幾行）
7. **新場次前空行規則**（是否強制、幾行——TNUA 明文兩行，MOC/GHSA 未明文）
8. **場次編號格式**：純數字 vs 含插入場次記號（如 12A）——本研究未找到任何範本的答案，需另外定義
9. **是否需要投稿包裝頁**（標題頁不署名、長版大綱、人物介紹、浮水印文字）——這是 GHSA 特有的、其餘兩份範本沒有的一層

## 不確定與缺口

1. **MOC 完整徵件須知全文未取得**——本次只取得標題為「『劇本內文』寫作格式參考」的 4 頁節錄文件，這很可能只是文化部劇本獎徵件須知的其中一個附件。頁面設定（紙張尺寸、邊界、字型、字級、行距）完全沒有出現在這份文件中，不代表文化部劇本獎真的沒有這些規定——只代表**這份文件沒有涵蓋**。需要另外取得完整徵件須知才能確認。
2. **場次標題是否可含人物欄位**——MOC/GHSA 範例沒有列人物，但沒有文字禁止列人物。無法確定「不列人物」是硬性規則還是範例剛好沒展示這個變化。
3. **場次標題是否加粗**——只能從 PDF 圖像判讀，MOC/GHSA 範例中看起來沒有明顯加粗，但這是視覺判讀而非文字屬性讀取，信心有限。
4. **對白前後空行、場次間空行的具體行數**——MOC/GHSA 範例排版上確實有空行，但沒有像 TNUA 那樣寫成文字規則（「須空一行」「須空兩行」），因此無法確認這是否為可省略的排版習慣，還是嚴格規則只是沒寫出來。
5. **簡表的歷史樣貌完全沒有一手範本佐證**——三份範本都是「現行規範」，沒有任何一份展示舊式簡表長什麼樣子、有哪些欄位。若專案需要理解或相容舊格式，這三份範本無法回答，需要另外找歷史範本或訪談業界人士。
6. **場次編號慣例（插入場次如 12A）——三份範本完全未規範**，這是本研究最明確的「空白」，不是信心不足，而是三份一手範本都沒有觸及這個情境。需要另外調查（例如：訪談台灣場記/製片統籌實務、或參考國際劇本軟體慣例）才能得到答案。
7. **GHSA 的投稿包裝規則（不得署名、浮水印、大綱字數）是否也適用於文化部劇本獎**——MOC 範本文件沒有重複聲明這些規則，只說內文格式「參考優良電影劇本獎」，無法確定 MOC 是否也要求投稿包裝，還是只借用了內文排版部分。
8. **三份範本之間，何者代表「業界普遍現況」**——本研究只能比較三份官方/教學範本互相的異同，無法評估台灣編劇實際工作時最常用哪一種寫法（例如行內式 vs 分行置中式哪個更普及），這需要業界問卷或訪談才能回答，範本本身無法回答「習慣上」的問題。
