# 47 — 遷移批次 3：改群演的名字，人數自動留著

**What to build:** 拿起一顆群演 chip 來改的時候，**框裡只有名稱**，人數不在那串字裡 ——
所以改名字**根本弄不掉人數**。那行唯讀提示要把這件事說出來：數量保留，不必手動重寫。

這是票券 41 第八輪的裁決，它比前七輪好的地方只有一句話：**最常見的那件事變成零成本。**
第七輪是「改描述會把人數弄掉，所以問一次」；這裡是不必問，因為弄不掉。少一關，而且少掉的
正是每次改名字都要走的那一關。

**Blocked by:** 45 —— 與票券 46 平行（兩者只共用 44 的型別，彼此不依賴）

**Status:** done

## 編輯狀態長這樣

```
編輯狀態啟動（三個入口，都已經存在且同一條路）
  · 點 chip     · 空欄位 Backspace 退到它    · 焦點在 chip 上按 Enter
        ↓
  全選內文 ＋ 展開下拉選單
        ↓
  框裡是**名稱**，人數不在裡面 —— 直接改文字 ＝ 只改名稱
  唯讀提示：數量保留，不必手動重寫
```

## 編輯框**不認** `路人 x8` 的尾綴

票券 41 第九輪收回了「編輯框也認」那個建議。編輯框的合約是「這裡面是名稱」，那行提示也
正這麼說。一旦它同時認尾綴，同一個框就有兩種意思，而且此刻人數**已經有一個現值**，於是有
三個東西要調和：現值 8、框裡打的尾綴、選單裡挑的值。三者衝突時誰贏，**沒有一個編劇猜得到
的答案**。

⚠️ **新增路徑照舊認** `路人 x8` —— 那個框的合約不同：它從零開始，整串都還沒定案。
同一個輸入框在兩種狀態下讀法不同是可以的，因為狀態本身看得見（chip 外殼在不在）。
新增那一側在票券 49。

## 票券 40 那三列一個字都不用改

`✏️ 把「A」改成「B」`／`↩︎ 不修改，返回`／`＋ 新增「B」群演，保留「A」` 印的是**整串前後
對照**（`路人（8）` → `保全（8）`），所以描述與人數誰變了都讀得出來。名稱改了、人數沒動時
它自己就說對了。

## 握著就是修改 —— 把字刪光也一樣

拿起一顆 chip 把字刪光之後，剩的是那個 chip 外殼（記號、邊框、× 都還在，只有字沒了）。
那個外殼**就是「還握在手上」的證據**：`extraId` 還在，指著它的對白也還指著它。所以這一刻
重打字，改的是**同一批人**（id 不變），選單照樣印 `✏️ 把「路人（8）」改成「保全（8）」`。

真的想重新定義一批，路已經在那裡而且寫著：框裡空著時**再按一次 Backspace ＝ 放手**，
欄位回到空的，這時打字才是新增。

⚠️ 連帶的既有行為要保住：**框裡空著離開欄位 ＝ 放手，那一批就沒了**（`extras-field.tsx`
的 `onBlur`）。

## 未決（不擋這張票）

放手那一下要不要也能 ⌘Z 還回來（票券 37 立的前例：undo 還回編劇打的字）。票券 41 第六輪
列為待確認，這裡照樣列著 —— 它是既有行為的延伸，不是這一批的新洞。

## 驗收

- [x] 三個入口（點 chip／空欄位 Backspace／chip 上 Enter）都進**同一個**編輯狀態：全選內文＋展開選單
- [x] 框裡只有名稱，不含括號也不含人數
- [x] 直接改文字 ＝ 只改名稱，**人數自動保留**
- [x] 那行唯讀提示說得出「數量保留，不必手動重寫」，而且它不是一列選項（選不到、Enter 碰不到）
- [x] 編輯框**不認** `路人 x8` 的尾綴 —— 那幾個字就是名稱的一部分
- [x] 票券 40 那三列一字不改地繼續成立，印的仍是整串前後對照
- [x] 握著一批、字刪光、重打 —— 仍是修改（`extraId` 不變），指著它的對白不懸空
- [x] 框裡空著再按一次 Backspace ＝ 放手；空著離開欄位也是放手
- [x] 本批次之外的呼叫點一個都沒改，**CI 綠**

## 實作時補的一個決定（code review 指出 spec 沒裁決）

**「另外開一批」那一列，新鑄的那一批沿用手上這一批的人數**（`＋ 新增「保全（8）」群演，
保留「路人（8）」`）。理由：框裡只有名稱，所以這一刻畫面上唯一的人數就是手上那一批的 ——
系統要嘛沿用它，要嘛憑空宣告一個數字（正是票券 41 要消滅的東西）。代價寫在那一列上，
按下去之後那一批就在欄位裡，想改人數走人數那條路。

⚠️ 連帶的退路：**「另外開一批」現在開不出不同人數的一批**（得先建立、再改人數）。
票券 49（新增路徑）決定人數怎麼輸入時，這一列要不要跟著走同一條路，留在那裡一起看。

## Comments

### 2026-09-12 — 人工驗收的三則回饋

1. **「不修改，返回」在字改過之後不見了。** 屬實：它原本是第一列在「字沒改」那一格的措辭，
   所以一改字就被 `✏️ 把「A」改成「B」` 換掉。已改成**自己一列、握著一批時永遠在**，按下去
   是整輪作廢（那一批原封放回、打的字丟掉）；字沒改時它是唯一那一列，不印兩次同一句話。
   通則是票券 42 第 2 條，42 本身只管人物／地點欄，群演欄這一側沒有票在管，補在這裡。
2. **放手之後的 ⌘Z 還回來的是一串裸字、人數掉了。** 已切成**票券 53**。不是這一批的迴歸
   （裂縫在票券 37 那條線上：那串字從來不在 doc 裡），但 47 之前那串字是 `路人（8）`、尾綴
   會被讀回來，歪打正著保住了人數，47 之後只剩名稱，於是人數真的掉了。文件那一側是好的
   （直接 `editor.commands.undo()` 完全正確），壞在那顆鍵到不了文件。
3. **唯讀抬頭要改成兩態、並指路到「修改數量」。** 措辭已逐字寫進**票券 48**，並與
   `修改數量…` 那一列**同時上線** —— 那一列是 48 造的，先換文案等於叫編劇去點一個不存在的
   選項。所以 47 這一版維持 `改的是名稱 —— 數量保留，不必手動重寫`。
