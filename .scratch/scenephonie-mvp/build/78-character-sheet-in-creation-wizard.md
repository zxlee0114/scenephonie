# 78 — 建立精靈的「人物介紹」頁籤

**What to build:** 票 71 建立精靈第 2 步（文件）多一個**人物介紹**頁籤，跟故事大綱、分場大綱並排。編劇在建立專案之前就能
列出人物、寫好每個人的介紹內文；按下建立時，人物連同角色設定表一起建好。

**Blocked by:** 21（第 ② 片：角色設定表）、71

**Status:** needs-triage

## 為什麼不是把編輯器放進去就好

精靈是**還沒有專案的本機草稿**，而角色設定表上每一筆都是**人物實體的引用**（ADR-0005）—— 實體屬於專案，專案還不存在時
建不起來。票 21 第 ② 片的編輯器在「＋ 加入人物」那一刻就呼叫伺服器建人物，這在精靈裡做不到。

所以這一頁籤要的是：

- 草稿裡存**名字與內文**（`{ name, description }[]`，依順序），不存人物 id。
- 建立專案的那一個交易（票 71 第 7 條）裡：專案 → 劇本 → 故事大綱 → 分場大綱 → **依序鑄人物、寫角色設定表**。
- 精靈裡沒有劇本，自動補全沒有東西可以命中（同名的兩行就是兩位人物 —— 要不要擋，開工前定）。

## 開工前要定

- 頁籤的樣子跟文件頁一樣（名字當標題、內文在底下），還是更精簡？
- 確認步驟的摘要怎麼寫人物介紹（「3 位人物」？0 位寫「尚未開始」？）
- 同名兩行怎麼處理。
