# 19 — 匯出前防呆

**What to build:** 彈窗的語意是**「這份 PDF 會少掉這幾場」**，不是「要不要輸出這一場」（草稿本來就不輸出）。列出被略過的草稿，每筆**附內容首行摘錄**（`S11[D1]` 對編劇是個空號，首行文字才是他認得出來的東西）；未填的 metadata 逐項標明（「未填寫內／外、地點」）。**支援多選與全選。** 「之後不再提醒」勾選記 `sceneId`。**即使全部勾了「不再提醒」，輸出完成後仍要顯示一行「本次略過 N 場草稿」** —— 不擋流程、不需點掉（靜默地少印幾場，對一個要拿去投劇本獎的人是最糟的失敗模式；防呆的價值在這裡，不在彈窗本身）。**草稿成員 → 整個群組印不出來**（殘缺的對剪比不印更糟），草稿清單要**特別標示「這場屬於一個對剪群組」**。**登場人物提示另外列，提醒但不阻擋**（§4.7）—— 與草稿分開，因為它可能是正確狀態，拿去攔匯出是製造假警報。
