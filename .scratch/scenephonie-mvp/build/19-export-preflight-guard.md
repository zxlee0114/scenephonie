# 19 — 匯出前防呆

**What to build:** 彈窗的語意是**「這份 PDF 會少掉這幾場」**，不是「要不要輸出這一場」（草稿本來就不輸出）。列出被略過的草稿，每筆**附內容首行摘錄**（`S11[D1]` 對編劇是個空號，首行文字才是他認得出來的東西）；未填的 metadata 逐項標明（「未填寫內／外、地點」）。**支援多選與全選。** 「之後不再提醒」勾選記 `sceneId`。**即使全部勾了「不再提醒」，輸出完成後仍要顯示一行「本次略過 N 場草稿」** —— 不擋流程、不需點掉（靜默地少印幾場，對一個要拿去投劇本獎的人是最糟的失敗模式；防呆的價值在這裡，不在彈窗本身）。**草稿成員 → 整個群組印不出來**（殘缺的對剪比不印更糟），草稿清單要**特別標示「這場屬於一個對剪群組」**。**登場人物提示另外列，提醒但不阻擋**（§4.7）—— 與草稿分開，因為它可能是正確狀態，拿去攔匯出是製造假警報。

## Comments

**2026-10-22 實作（PR 待開）。** 開工前的兩個裁決（使用者）：

1. **「不再提醒」存成場次 attr** `draftReminderDismissed`（不允許 null、default false），走 command
   `dismissDraftReminders({ sceneIds })` —— 多選一次寫入、⌘Z 一步撤回；有一個 id 找不到就整批拒絕。
   記在場次上就是「記 `sceneId`」：拖到哪、標籤換成什麼都跟著它，刪場次一起走。
2. **清單放進既有的匯出面板**，按「匯出」直接印，不多一步。

落點：

- `packages/schema/src/export-preflight.ts` 的 `exportPreflight(doc)`：`drafts`（還要提醒的草稿：標籤、首行摘錄、
  理由、群組後果）、`skipped`（`{ drafts, groupMates }`，**含不再提醒過的**）、`appearing`（登場人物提示）。
  - **誰被略過讀交付同一份**：`delivery.ts` 抽出 `deliveredRows(doc)`，`projectDelivery` 與預檢共用。
  - **草稿理由由 `projectScenes` 那一次走訪記下**（`DraftReason`：手動、缺欄、沒有內文、與主場次相同、與同組撞時空、
    主場次是草稿）—— 不另判一次。`isSceneMetaIncomplete` 換成 `missingSceneMeta`（回傳缺哪幾欄，空 ＝ 完整）。
  - 登場人物提示逐句問票 10 的 `unlistedSpeakers`，**只看會印出來的場次**（草稿與殘缺群組不提 —— 它們本來就不印）。
- `apps/web/src/editor/export-pdf.tsx`：清單（多選、全選、之後不再提醒）、登場人物提醒另列（無勾選框）、
  印好後的「本次略過 N 場草稿」。預檢與寫入由 `ScreenplayEditor` 注入（它手上有 doc）。

實作時自定、待使用者驗收時確認：
- 摘錄照紙上的樣子：對白帶說話者（`小明：你來了`）；取第一個有字區塊的第一行，超過 20 字以「……」收尾；沒有內文印「（沒有內文）」。
- 草稿成員那一筆說「這場屬於一個對剪群組，整組都不會印：同組的 2、2.1 也會一起略過」。
- 印好之後若有殘缺群組，多一句「另有 M 場因為同組有草稿，整組一起略過。」—— 那幾場本身不是草稿，只說「略過 N 場草稿」會少算。
- 清單標題在有場次設成不再提醒時補「（其中 k 場已設成不再提醒，不列出）」；全部都設了就不出清單，只剩「草稿場次不會印出來。」。

**待確認的灰色地帶**：群組成員底下的**草稿子場次**不會讓整組印不出來（交付現況如此，`brokenGroups` 只看成員本身）。
§9.6 寫的是「草稿成員」—— 若子場次也該算，要改的是交付，預檢會自動跟上。

Code review（Standards／Spec 兩軸）之後改的：`SkippedCount` 取型別名、`GroupConsequence` 不再用非空斷言、
區域變數 `groupMates` 改名 `stranded`。沒採納：預檢裡「逐 container 跳過子場次」的迴圈與 `walk` 的片段查找重複 ——
抽共用要動 `sceneEntries` 的形狀，留著。

### 待人工驗收

1. 一場只填了時間的草稿、一場手動標記的草稿 → 打開匯出面板：「本次輸出會略過 2 場草稿」，各帶首行與「未填寫內／外、地點」「手動標記為草稿」。
2. 勾一場 →「之後不再提醒勾選的場次」→ 那一場從清單消失、標題補「其中 1 場已設成不再提醒」；⌘Z 撤得回來。
3. 全選 → 不再提醒 → 清單消失；按匯出 → 下載後顯示「已下載。本次略過 2 場草稿。」。
4. 對剪群組裡一個成員沒填完 → 清單那一筆說整組不會印、列出同組場次號；印好後多一句「另有 M 場…」。
5. 一句一般發聲的對白、說話者不在登場人物欄 → 面板另列「有台詞、但不在登場人物欄的人」，匯出照常。
