# 87 — 介面用語：不露工程詞，同一件事只有一種說法

**What to build:** 兩類用語問題：

- **工程詞露在介面上**：人物欄、地點欄的自動補全選單寫「建立新實體」「作為既有實體的另一個名字…」。「實體」是程式碼與規格的詞，
  編劇腦中的詞是「人物」「地點」。第一次使用的人看不懂第三列在問什麼。
- **同一件事三種說法**：場次表欄名「景／光」、場次表篩選框「時間」、編輯器抬頭「內外／時間」。sidebar 寫「S1」、編輯器 gutter 寫「1」。

**Blocked by:** 無（與 36、42、49 的選單措辭相鄰，見下）

**Status:** needs-triage
