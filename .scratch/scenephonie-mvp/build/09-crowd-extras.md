# 09 — 群演

**What to build:** 場次限定實體。場次上一個 `{ extraId, 描述, 人數 }[]` 清單（可多組：`咖啡廳客人 x8、服務生 x2`）。id 只在該場次內有意義，不進人物表。**入口不走 `/` 選單**（否決 `/extra`、`/crowd` —— 群演是 metadata 欄位而非區塊）—— 走內嵌簡表的群演欄 ＋ 對白人物欄的自動補全（可在那裡直接新建一筆，解掉「寫對白寫到一半跳去簡表」的心流問題）。描述可跨場次自動補全，但**只補字串、不建立連結**（不做「這是同一批人」的假承諾）。對白的人物欄合法目標是「人物」或「本場次的群演」；分界：**一個人說話 → 人物**（即使名字只是「路人甲」）；**一群人齊聲說 → 群演**。群演進場次表第一層（唯一消費者），**不進 PDF**。跟著場次被複製時一起複製（**不去重** —— id 只在該場次內有意義，跟著複製是正確的）。「臨演」與「群眾演員」不拆；「特約」不是群演（那是有台詞的小角色，已被人物吸收）。
