# 60 — 對白人物欄：游標走到 chip 前面時，輸入框把 chip 推到中間

**What to build:** 對白人物欄裡有一顆 chip，游標從隊尾按兩下 ← 走到 chip **前面**，版面變成：

```
|                    [+ jfifji ×]      ← 現在：輸入框在 chip 前面撐開，chip 被推到欄位中間
|[+ jfifji ×]                          ← 該有的樣子：游標住在那道縫裡，整排一動也不動
```

CONTEXT.md「chip 之間那道縫」一段定的是：游標插進去、還沒打字時，輸入框**寬度固定而且不佔版面**
（一格游標寬、左右負邊距還回去，後面那道縫收成零）—— 連第一顆 chip 左邊也成立。對白人物欄
沒有照這一條走。
