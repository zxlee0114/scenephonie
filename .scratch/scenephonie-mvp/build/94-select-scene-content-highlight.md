# 94 — ⌘A 選到本場內文時，反白看起來亂掉

**What to build:** 在對白的台詞裡按 ⌘A（第二層：本場內文，§7.1）時，畫面上的反白看起來不是「這一場的內文」：

- 第一句對白的**人物 chip 沒有反白**，只有它的台詞（「說話。」）是藍的；
- 後面幾句對白卻是**整塊**變藍（人物欄連台詞一起，含 chip 之間的縫），樣子與第一句不一致；
- 空台詞的對白也整塊變藍，看起來像多選了一個不知道是什麼的東西。

使用者讀成「選到了上方的台詞，以及下方的區塊」。

**Blocked by:** 無

**Status:** needs-triage

## 已知的（還沒查到底）

- 範圍本身大概是對的：`extensions/select-scope.ts` 的 `progressiveSelectAll` 第二層是 `TextSelection.between(場次內文開頭, 結尾)`。
  `between` 把起點挪到第一個合法文字位置 —— 也就是第一句對白的**台詞**裡，所以第一句的人物欄落在範圍之外。
  後面幾句整個在範圍裡，瀏覽器就把它們的 node view（人物欄是 React 畫的、`contenteditable=false`）整塊塗藍。
- 空區塊上第一次 ⌘A：區塊層的範圍是空的（`from === to`），於是直接跳到第二層。這是不是要的，也一起看。

## 開工前要定

- 第一句的人物欄算不算「本場內文」？算的話，⌘A 之後按 ⌫ 會連人物引用一起刪 —— 與 `scoped-delete` 的規則對一下。
- 反白要怎麼畫才一致：人物欄跟著台詞一起變藍（整句），還是只塗文字、chip 用自己的選取樣式（票 57 的 chip 選取）？
