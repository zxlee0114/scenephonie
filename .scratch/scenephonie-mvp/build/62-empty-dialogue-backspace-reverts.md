# 62 — 空的對白（人物欄與台詞都空）按 Backspace 不會收回區塊

**What to build:** 一句對白人物欄與台詞都是空的，在裡面按 Backspace **什麼都沒發生**。編劇預期
這一下把這個對白區塊收掉。

已經有的對應手勢：空的對白按 **Enter** ＝ 取消型別、退回描述（`extensions/continue-block.ts`，
`isBlankBlock`，使用者回饋 2026-09-03 第四輪）。開工前要問：Backspace 是

1. 同 Enter：退回描述（action），區塊還在；還是
2. 整個區塊拿掉、游標回上一個區塊尾端（一般文字編輯器對空段落 Backspace 的樣子）。

也要確認 Backspace 是在**哪一格**按的：台詞空的內文裡，還是人物欄的空輸入框裡（後者的 Backspace
現在歸欄位 —— 拿游標左邊那一顆 chip，見 CONTEXT.md「chip 之間那道縫」）。兩處可能都要接。

## Comments

**2026-10-26 — 票 21 驗收時撈到更嚴重的同一組手勢，併進這張，範圍擴大。**

使用者回報兩件事，跟原本的「空對白按 Backspace 沒反應」是同一個問題：**對白區塊之間的 Enter／Backspace 不對稱**。

1. **在對白最前面按 Enter，會切出第二句對白**：上面那句留著人物 chip、台詞變空；下面那句人物欄空著（placeholder「人物」）、
   台詞是原本的字。接著按 Backspace **併不回去**。本機資料裡第 2 場有兩句 `character: null` 的對白，就是這樣來的。
2. **會刪錯東西（資料遺失）**：在上述狀態下，把下面那句的台詞刪光（例：`yo`）再按一次 Backspace，被刪掉的是**上面那句有人物的
   對白**（「我是龍」連 chip 一起消失），只剩下空的那句。原本這張票寫的是「什麼都沒發生」，現在的行為比那更糟。

開工前要定的事多了兩題：

- 對白最前面（台詞開頭）的 Enter 應該做什麼？在上方插一段描述、在上方插一句空對白，還是不切？
- 從 1 的狀態按 Backspace，應該是 1 的反向操作，把兩句併回一句、保留上面那句的人物嗎？

驗收清單補兩條：

- [ ] 對白台詞開頭按 Enter 的行為（開工前定），而且按 Backspace 回得去
- [ ] 空對白按 Backspace 永遠不會刪掉**別的**區塊（第 2 點的資料遺失）

因為有資料遺失，建議這張排在 59～61 那幾張對白欄位的票前面處理。

**2026-10-26 — 拷問定案（grill-with-docs）。** 開工前要定的事全部定了，以下取代上面兩段的「開工前定」。

用語（已寫進 CONTEXT.md）：**對白**＝區塊，由**人物欄**與**台詞**兩格組成。

### 不變式（Q2）

**Backspace／Delete 不會刪掉、也不會併掉一句帶人物的對白** —— 人物只會在編劇一步一步拆的時候消失。
「帶人物」＝人物欄裡至少一筆顯示名非空白（與 `isBlankBlock` 同一條線）；一筆或齊聲多筆都算，
**懸空引用也算**（顯示名照印，見 CONTEXT.md 群演第 2 條）—— 看顯示名，不看引用目標還在不在（Q13）。

### Enter

- **台詞有字、游標在台詞開頭** → 在**上方**插一句空對白；原句的人物（整串）與台詞不動，焦點進新那句的人物欄（Q3）。
  規則：在台詞開頭切開時，沒有字的那一半是新的那一半。這一下**不觸發**登場人物提示 —— 那不是「寫完一句」（Q10）。
- **台詞中間** → 維持現狀：上半段留人物、下半段重新指定說話者，照舊問登場人物。
- **有人物、台詞空** → 維持現狀：新對白開在**下面**（Q11）。Q3 只在台詞有字時生效。

### Backspace（人物欄的空輸入框與台詞開頭視為同一個位置）

| 這一句 | 結果 |
|---|---|
| 空對白（無人物、無台詞） | 整句拿掉，游標回上一個區塊的文字尾端；**拿掉的永遠是這一句**，上一句不碰（Q4）。上一個兄弟是子場次時，落在子場次最後一個區塊。⌘Z 一下回來。 |
| 　└ 是一段內容（場次／子場次／片段）的第一個區塊 | 下面還有區塊 → 照樣拿掉，游標落到下一個區塊開頭（「台詞開頭 Enter → ⌫」在哪裡都回得去）；拿掉之後這段內容會空掉或以子場次開頭 → 退回成空描述，區塊留著（Q7，經 Q14 收窄：code review 時發現 Q3 與 Q7 在第一個區塊互相衝突，2026-10-26 裁決） |
| 有人物（台詞空或有字） | 走進人物欄，**拿起最後一顆 chip**（整串反白），接上三段式 Backspace：拿起 → 清空 → 放手（Q5）。齊聲時一顆一顆走、不另開「整串清掉」捷徑（Q12）。拆光之後再按，才依台詞空或有字，走「空對白」或「無人物、台詞有字」那一列。 |
| 無人物、台詞有字 | 台詞併進上一個區塊文字尾端，上一個區塊的型別與人物保留（＝台詞中間切開的反向）（Q6）。第一個區塊時什麼都不做（Q7）。 |
| 從描述／插入畫面開頭按，上一句是「有人物、台詞空」的對白 | **併不刪**：字接進那句的台詞，人物保留，游標停在接縫（Q8）。 |

### Delete（往前刪）

下一句帶人物時什麼都不做（Q9）。⌘⌫ 在行首等同 ⌫。有人物、台詞空的這一句按 Delete：同層下一行可以接就併進台詞，否則（下面是子場次、它是這段內容最後一個區塊）什麼都不做 —— code review 實測過預設的 `joinForward` 會跨層把它整句刪掉。

### 根因（實作線索，已對照程式碼）

- 人物欄空輸入框的 Backspace 沒有人接手：`entity-field.tsx:1262` 找不到左邊的 chip 就落空 —— 原票「沒反應」其實在這一格。
- 台詞內文的 Backspace 走 PM 預設 `joinBackward` → `deleteBarrier` → `joinMaybeClear`：上一個區塊**內文**為空就刪掉
  上一個，不看 attrs —— 「我是龍」就是這樣沒的。
- `tr.join` 保留前一個節點的 attrs，後一句的人物被丟掉（有人物、有台詞的對白在描述後面按 ⌫ 也中）；`joinForward` 同理。
- `continue-block.ts` 的 `tr.split` 在 offset 0 切開時，原 attrs 留在空的上半段。
