# 10 — 登場人物提示

**What to build:** 提示不是推導 —— 推導替編劇做決定，提示只指出落差、決定權在他手上。觸發條件：某人物在本場有**一般**發聲方式的對白，且不在本場的登場人物欄。標了 V.O./O.S. 的**絕不提示**（編劇已明確宣告那個人不入鏡）；反方向（在登場人物欄但沒台詞）也不提示。提示是一個**可忽略的選單**：`＋ 新增為登場人物` ／ `✕ 不新增 —— 他不入鏡`。**ESC 與「不新增」語意刻意分開**：ESC ＝「現在別煩我」，不記錄任何判斷、下次還會提示；「不新增」＝明確判斷，存進場次的 `dismissedCharacterIds`，這一場的這個人不再提示。「不再提醒」記的是 `sceneId`（標籤只負責讓人在彈窗裡看懂是哪一場）。系統不自動把有台詞的人加進登場人物欄。

**Blocked by:** 08, 09

**Status:** ready-for-agent

- [ ] 有「一般」對白但不在登場人物欄的人物觸發提示；V.O./O.S. 不觸發
- [ ] ESC 後同一場同一人下次仍提示
- [ ] 「不新增」寫入 `dismissedCharacterIds`，該場該人不再提示
- [ ] 提示可完全忽略，不阻擋寫作
- [ ] 推導不自動把有台詞的人加進登場人物欄
