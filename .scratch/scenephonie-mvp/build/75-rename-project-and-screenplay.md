# 75 — 改專案名稱與劇本名稱

**What to build:** 讓編劇在建立之後改**專案名稱**與**劇本名稱**（兩個不同的值，見 CONTEXT.md）。

**Blocked by:** 71（劇本名稱這一欄在那張票長出來）

**Status:** needs-triage

## 為什麼

票 71 讓兩個名稱在建立時都必填，但目前**任何地方都不能改專案名稱**（票 71 原第 3 條「留白、之後在 hub 改」
預設了一個不存在的功能）。71 上線之後打錯的名字改不回來，所以緊接 71 做。

從 71 拆出來是因為改名要定的事跟建立流程無關（2026-10-24 grilling）。

## 開工前要定的事

- **專案名稱在哪裡改**：hub 大標題點了就改（inline），還是選單裡的一項？儀表板卡片上要不要也能改？
- **劇本名稱在哪裡改**：hub 的劇本卡片、劇本編輯器頂端，還是兩處都可以？
- **規則**：能不能改成空白（建立時是必填，照理改名也不行）、長度上限、前後空白。
- **⌘Z**：改名回不回得來？票 39 的實體改名是「⌘Z 回不來的動作」，同一類問題。
- **劇本名稱改了之後**：交付 PDF 檔名讀現值（71 已定），舊交付的檔名會跟著變 —— 確認可以接受。
