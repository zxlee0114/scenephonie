# 40 — 改一批群演，選單要說它真的在做的事

**What to build:** 群演欄的 chip 拿起來改的時候，選單只有一列，而且它寫錯了：

```
＋ 新增群演「路人」1 人      ← 寫著「新增」，做的是「把手上那批改成路人」
```

`extras-field.tsx` 的 `toExtra` 會沿用握著那一筆的 `extraId`（票券 09 的裁決：保住 id，
否則指著它的對白當場懸空），所以那一下**是就地改名**。人物／地點欄在票券 39 之後已經把
每一條路寫在按下去之前，群演欄一條都沒寫。

**Blocked by:** 39（那份選單的形狀與「代價寫在按下去之前」的做法）

**Status:** done

## 這不是票券 39 的第十四輪

39 補的三列（`指回同一筆` ／ `✏️ 把實體改名（N 場）` ／ `🔗 作為既有實體的另一個名字…`）
之所以存在，是因為實體**有別場** —— 按下去會不會動到別場，就是那三列在講的事。

群演沒有別場（CONTEXT.md：場次限定的實體，第 3 場的路人與第 7 場的路人不是同一批人），
所以那三列在它身上無話可說。它缺的是另外兩條，而那兩條 39 沒有處理。

## 缺的兩條

### ① 改這一批（今天預設會走，但沒說）

握著一批、框裡的字與原本不同時，預設那一列該說的是「把這一批改成 X」，不是「新增」。
它不必寫場數 —— 群演本來就只影響這一場，這正是它與 39 那列的差別。

⚠️ 描述與人數是同一列裡的兩件事（`路人 x3` → `路人 x8`）。改人數與改描述都是同一個動作、
同一個 id，這一列要能同時把兩者的變化說清楚，或者至少不誤導。

### ② 另外開一批（今天做不到）

人物欄握著一筆時可以選「＋ 建立新實體」，留著原本那筆、另外造一筆。群演做不到 ——
`toExtra` 一律沿用握著那一筆的 id，想留著只能先放手再打一次。

編劇的實際情境：拿起 `路人 x3` 想改人數，改到一半發現其實是另一批人（`保全 x1`），
這時他要的是兩批都在，不是把路人換掉。

## 不在範圍

- **群演的跨場次身分。** 使用者在 39 的驗收裡提過「對編劇來說群演跟其他實體是同樣東西」；
  若那句話要兌現成資料層的身分連續性，那會動到 CONTEXT.md:297-321 的核心裁決與 schema，
  是另一件事。這張票只讓**修改的進行模式**與人物／地點一致，不動「它是什麼」。
- **抬頭（`heldNote`）。** 人物拿起來會顯示「這一筆在 N 場用到」；群演沒有場次數可以數。
  要不要給它一句別的抬頭（例如「這一批只在這一場」），等 ① ② 做完再看要不要。

## 驗收

- [x] 握著一批群演、把字改掉 → 選單那一列說的是「改」，按下去也是改（id 不變，指著它的對白不懸空）
- [x] 握著一批群演 → 有一條路可以留著原本那批、另外開一批（id 不同）
- [x] 這兩條的措辭與人物／地點欄讀起來是同一套（動詞在前、影響範圍寫在按下去之前）

## Comments

### 2026-09-11 — 收票

**① 改這一批。** 第一列改印 `✏️ 把「路人 x3」改成「路人 x8」` —— 兩邊都印整串
`描述 x 人數`，所以「改描述」「改人數」「兩個一起改」都是同一列、都讀得出來，不必為人數
另外造一句話。不寫場數（票券 39 那三列寫場數，是因為實體有別場）。

**字一個都沒改時**印 `↩︎ 放回「路人 x3」` —— 那一下確實什麼都沒動，說「改」會是假的，說
「新增」更假。手上沒握著東西時維持原本的 `＋ 新增群演「X」N 人`。

**② 另外開一批。** 只在**握著一批而且字改了**的時候出現：
`＋ 另外開一批「保全 x1」 —— 原本的「路人 x3」留著`。手上沒握著東西時「新增」本來就是
另外一批；字沒改時它只會造出一批一模一樣的，那不是編劇這一刻要的。實作是
`extras-field.tsx` 的 `addAnother`：握著那一筆放回原本那一格，新的一批鑄新 id 緊接在後。

`✏️` 的意思在 `field-marks.ts` 裡從「改實體本身」放寬成「就地改手上那一筆」—— 兩個欄位
的用法在這一點上是同一件事，只是群演這一側沒有實體可以改。放回那一列另給 `↩︎`：`👥` 是
**身分**標記（「這東西是群演」），而同一份選單裡它已經是「把這串字填回輸入框」的補字列，
同一個記號不該在一份選單裡帶兩種行為。

CONTEXT.md 的「群演」詞條（實作定案第 2 條）跟著補上這兩列的措辭與「不寫場數」的理由 ——
它與「重新編輯保住 id」是同一件事的兩面：因為就地改，所以選單得說「改」。

### 2026-09-11 — 第二輪（編劇回饋）

**措辭三改**（編劇指定）：

| | 原本 | 現在 |
|---|---|---|
| 字沒改那一列 | `↩︎ 放回「路人 x3」` | `↩︎ 不修改，返回` |
| 另外開一批那一列 | `＋ 另外開一批「保全 x1」 —— 原本的「路人 x3」留著` | `＋ 新增「保全 x1」群演，保留「路人 x3」` |
| 抬頭 | （沒有） | `✏️ 正在編輯「路人 x3」，修改文字可更新名稱、人數` |

「不修改，返回」把名字省掉，是因為**抬頭已經印著它**：兩行疊在一起時「正在編輯「路人 x3」
／放回「路人 x3」」會把同一串字說兩次。

**抬頭從「不在範圍」變成要做。** 原本的理由是「群演沒有場次數可以數」—— 那誤判了抬頭在講
什麼：實體欄那一行講的不是場次數，是**我在編輯誰、改這裡的字會怎樣**（票券 39 收票）。群演
一樣需要它，而且更需要：那一格能改的是**兩件事**（名稱與人數），少一個字就少說一半。所以
它與實體欄逐字同一套，只差「、人數」：

```
✏️ 正在編輯「路人 x3」，修改文字可更新名稱、人數      ← 框裡有字
✏️ 正在編輯「路人 x3」，再按一次 Backspace 移除這一批  ← 框裡空著
```

空著那一行與實體欄措辭不同（那邊是「移除這一場的引用」）：群演沒有跨場次身分，這一場移掉
它就沒了，說「這一場的引用」反而暗示別處還有一份。

**未進本票的兩件事**（見下方「延伸」）：人物／地點欄的「不修改，返回」一致化、群演人數的
「大概就好」。
