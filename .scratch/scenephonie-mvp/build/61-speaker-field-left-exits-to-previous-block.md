# 61 — 對白人物欄：在最前面按 ← 走不回上一個區塊

**What to build:** 對白人物欄的游標已經在最前面（第一顆 chip 前面、或空欄位），再按 ← **沒有反應**。
該有的行為：走出這一格，回到**上一個區塊的內文尾端** —— 同一顆鍵在內文裡跨區塊時的樣子。

開工前要確認的：

- ↑ 從人物欄出去是不是已經會回上一個區塊（`chip-nav.ts` 有 `exitUp`／`exitDown`，沒有向左的出口）；
  ← 要不要與 ↑ 同一個落點。
- 場次第一個區塊是對白時，← 的上一站是不是場次抬頭的 chip row（地點／登場人物欄）。
- 反方向：上一個區塊內文尾端按 → 會不會走進這一句的人物欄（對稱與否要問）。
