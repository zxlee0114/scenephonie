# 89 — 從上面走進對白，要不要先停在人物欄

**What to build:** 現在從上方走進一句對白，不管按哪顆鍵，游標一律落在**台詞**、跳過人物欄：

- 上一個區塊末端按 → 或最後一行按 ↓
- 場次 chip row 按 ↓／→（最後一格）／Enter／Tab（`nodes/scene` 的 `enterBody`）

反方向卻是先經過人物欄（台詞開頭 ←／第一行 ↑ → 人物欄 → 再一下才出去）。票 61 補上人物欄的 ← 之後，
來回的路線是：人物欄 ← → 上一段末端 → → 台詞開頭 ← → 人物欄。環沒斷（§7.3），但去跟回不是同一條路。

**Blocked by:** 61

**Status:** ready-for-agent

## 定案（grilling 2026-10-27，與 82、91 一起跑）

- [ ] **方向鍵照畫面幾何走**：上一個區塊末端按 →、最後一行按 ↓，下一個區塊是對白時**一律先停人物欄**（不論人物欄空不空），
  再一下才進台詞 —— 與 ↑／← 回程同一條路。同 61「照畫面上下走」的原則（`memberNeighbours`）。
- [ ] **chip row 的 ↓／→（最後一格）／Tab** 進內文、第一個區塊是對白時，同樣落**人物欄**。Tab 是依序經過每一格，
  人物欄是台詞前一格。人物欄已有人時多付的只是一下 Enter（82：輸入框空著時 Enter ＝ 進台詞）。
- [ ] **chip row 的 Enter 不在本票** —— 它改成「在內文最上方插一個描述」，見 91。
- [ ] 新開一句對白（`/對白`）本來就落人物欄，不受影響。
- [ ] 89 與 91 都會動 `nodes/scene` 的 `enterBody`（Enter 與 Tab 從此分家），接著做或併成一條分支。
