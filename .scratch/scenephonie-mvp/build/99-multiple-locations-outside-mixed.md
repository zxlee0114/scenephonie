# 99 — 不是雜景的場次打了好幾個地點：要怎麼回應

**What to build:** 地點欄只有**雜景**會照分隔符拆成好幾個地點；其他場次（內景、外景、內外景，以及**內外還沒填**的場次）
是單值欄，打「巷口、警局」會變成**一個**叫「巷口、警局」的地點。編劇不確定這樣好不好 —— 尤其內外還沒填的時候，
他可能根本還沒決定這一場是不是雜景。

**現行規則**（`CONTEXT.md`「雜景」，票券 15）：雜景承認橫跨多地，所以地點欄可以有多個值；其他任何場次的 metadata 一律單值。
想嚴謹時把雜景升級成場次群組。

**開工前要問（grilling）：**

- 單值欄打了分隔符，是「名字裡的普通字元」（現行），還是一個訊號？可能的回應：照舊、在選單裡提示「這一場要改成雜景嗎？」、
  直接拆成場次群組……
- 內外未填的場次算不算例外：先讓它多值、等內外定了再收？還是照單值？
- 會不會碰到 CONTEXT.md 的不變式（時空一變就是新場次）—— 改的話要先動詞條。
