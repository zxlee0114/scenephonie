# 56 — 剛新增的群演，同一場的對白人物欄當下看不到（bug）

**症狀：** 在群演欄新增一批（例如 `保全（8）`）之後，游標移到同一場的**對白人物欄**打字 ——
選單裡沒有那一批：齊聲那一列不在、升格那一列也不在。反過來也一樣：在群演欄**改了人數**
（`路人（1）` → `路人（3-5）`），升格那一列印的還是舊數量（`從「路人（1）」裡升格一個人`）。
離開這一場再回來、或重新整理之後就對了。

**Status:** in-review

## 為什麼

對白那一行是自己的 **NodeView**，而群演住在**場次 node 的 attr** 裡。ProseMirror 只在一個
node 自己的 attr 或內容變動時重繪它的 view —— 場次 attr 改了，底下那些對白 node 一個都沒動，
於是它們手上的 `sceneExtras` prop 還是掛載當時那一份。

**不是票券 49 造成的**（那批只改措辭與新增流程）。這條裂縫從對白人物欄能讀群演的那天就在
（票券 35 升格、§5.1 齊聲），只是那之前群演的人數不會在畫面上被讀出來，看不出來而已。

## 這張票要決定的事

`sceneExtras` 是**一個函式**（同 `EntityField.usage`）—— 呼叫端每次重繪都會問，所以值不會
過期，過期的是「重繪這件事沒有被觸發」。三條路，選一條：

1. **場次 node 的 view 在 attr 變動時把底下的對白 view 一起標記為待更新**（最直接，但要
   確認不會把整場對白的游標／組字狀態洗掉 —— §7.6 那條「注音組字期間不動作」在這裡也算數）。
2. **對白的 NodeView 訂閱那一格 attr**（範圍最小，但每個 view 各自訂閱一次）。
3. **升格／齊聲那幾列改成在開選單的那一刻才去讀 doc**，不吃 prop（把「什麼時候重繪」這個
   問題整個繞開；代價是那幾列與欄位其餘部分的資料來源不同）。

## 驗收

- [x] 群演欄新增一批之後，**不離開這一場**，同一場的對白人物欄看得到它（齊聲 ＋ 升格兩列）
- [x] 群演欄改過人數之後，升格那一列印的是**新的**數量與新的「剩多少」
- [x] 群演欄刪掉一批之後，那兩列跟著消失
- [x] 對白欄正在組字／正握著一筆時，群演欄的改動**不打斷**它（§7.6）
- [x] 一條測試走過整台編輯器：群演欄寫入 → 對白欄讀得到（現有的整合煙霧測試就在隔壁，
      票券 49 為了繞開這條限制把升格那一半跑在初始 doc 的那批人身上）

## Comments

### 2026-09-13 —— 開票

票券 49 的人工驗收撞到（兩次：新增之後沒有升格列、改過人數之後升格列印舊值）。當下判定是
既有行為、不在那批範圍，記在票券 49 的 Comments 裡並開這張票。

### 2026-09-26 —— 實作：選第三條路

`EntityField.sceneExtras` 從陣列改成**函式**（與 `usage` 同一個形狀）；對白的 node view 給的是
`() => extrasHere().map(...)`，欄位在**自己每次重繪**時才問。打字就是重繪 —— 編劇移到對白欄
打字的那一刻，讀到的就是 doc 當下的群演。

不選 1、2 的理由：兩條都要讓場次 attr 的變動去**驚動**對白的 view（重繪或重掛），而那正是
§7.6 要擋的東西 —— 組字中、正握著一筆時被重掛，輸入就被洗掉。3 完全不碰 view 的生命週期，
§7.6 那一格是白送的。票上寫的代價（「那幾列與欄位其餘部分的資料來源不同」）實際上不存在：
`usage` 本來就是同一個形狀，欄位裡本來就有「開選單才讀 doc」的那一半，群演只是歸隊。

殘留的一點：選單**已經開著**、編劇沒動對白欄、只在別處改了群演 —— 這時選單不會自己換。
但群演欄與對白欄不會同時有焦點，他回來一打字就換，所以驗收的情境都涵蓋得到。⌘Z 在對白欄
裡退掉一批群演時選單會多留一拍舊列 —— 點下去也寫不壞：舊 id 會被 `takeOneFromExtra`／
`setDialogueCharacters` 的不變式擋下，整次寫入放棄。

測試：`scene-extras.test.tsx` 的「對白人物欄跟著同一場的群演欄走（票券 56）」五條。前四條先紅
後綠（新增走整台編輯器的群演欄 → 對白欄；改人數、刪一批直接改場次 attr；組字中改 attr 不
打斷）；第五條（握著一筆時改 attr 不打斷）是護欄，修之前就是綠的 —— 這條路本來就不重掛。
全套 schema 241 / web 572 passed，typecheck 乾淨。勾選的五格是**測試涵蓋**，人工驗收還沒做。
